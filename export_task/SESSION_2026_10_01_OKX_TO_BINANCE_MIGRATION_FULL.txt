10. LESSONS LEARNED — KỸ THUẬT
=============================================================================

10.1 Go module naming conflict
    Khi rename module, tất cả import paths trong .go files phải được cập nhật.
    Dùng PowerShell replace over files toàn bộ thư mục:
      Get-ChildItem -Recurse -Include "*.go" | ForEach-Object {
          (Get-Content $_.FullName -Raw) -replace 'old-module', 'new-module' |
          Set-Content $_.FullName -NoNewline
      }

10.2 Hai file cùng khai báo type trong cùng package
    Khi có 2 file trong cùng package khai báo `type Config struct`:
    → Dùng `//go:build ignore` để loại file cũ ra khỏi build
    → Không xóa file (giữ làm reference / migration target)

10.3 BinanceTradeTick field names khác OKXTradeTick
    OKXTradeTick.Timestamp = time.Time   →  BinanceTradeTick.Timestamp = int64
    OKXTradeTick.Size                    →  BinanceTradeTick.Quantity
    → record.Time() phải gọi .UnixMilli() khi assign vào int64 field
    → Khi scan VPSMarketSnapshot không có Bid/Ask, phải xóa code đó

10.4 Pre-existing build errors cần phân biệt
    Luôn xác nhận lỗi có tồn tại trước task hay không bằng git stash test:
      git stash; go build ./...; git stash pop
    Nếu lỗi đã có → document là "pre-existing", không phải do migration gây ra

10.5 OKX Passphrase không có trong Binance
    OKXConfig có Passphrase (3-factor auth: apiKey + secret + passphrase)
    BinanceConfig chỉ có APIKey + SecretKey (2-factor: apiKey + HMAC signature)
    → Xóa Passphrase field và OKX_PASSPHRASE env var khi migrate
