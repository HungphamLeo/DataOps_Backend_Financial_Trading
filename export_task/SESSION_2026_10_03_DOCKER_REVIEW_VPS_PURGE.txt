3. LỖI BUILD THỰC TẾ ĐÃ GẶP VÀ GIẢI PHÁP
=============================================================================

Lỗi 1: bitnami/spark:3.5 not found
  Error: failed to resolve reference "docker.io/bitnami/spark:3.5": not found
  Root cause: Bitnami đã xóa toàn bộ images khỏi Docker Hub (migrate sang VMware registry).
  Fix: Đổi sang apache/spark:3.5.0 (official Apache image, confirmed tồn tại).
  Lưu ý: apache/spark không có SPARK_MODE env var như bitnami.
          Phải dùng command: ["/opt/spark/bin/spark-class", "org.apache.spark.deploy.master.Master", ...]

Lỗi 2: golang image tag tham chiếu
  Error: error getting credentials - err: exit status 1, out: ''
  Root cause: golang:1.27-alpine không tồn tại → Docker credential helper báo lỗi thay vì
              "image not found" bình thường — rất misleading.
  Confirmed: golang:1.27-alpine là valid tag. Lỗi thực tế có thể do golang:1.23-alpine
             thấp hơn go 1.27 trong go.mod → module download fail trong build step.

Lỗi 3: Compile error producer.go
  Error: undefined: constants.TopicVPSMarket (4 occurrences)
         undefined: constants.TopicVPSMarketDLQ (4 occurrences)
  Root cause: topics.go đã xóa VPS constants (chỉ còn comment DEPRECATED rỗng)
              nhưng producer.go vẫn tham chiếu — không đồng bộ giữa 2 files.
  Fix: Xóa hoàn toàn PublishVPSSnapshot() và mọi VPS reference trong producer.go
       thay vì add lại constants (không cần giữ backward compat).

Lỗi 4: Dockerfile COPY/CMD bị cắt ngắn
  Symptoms: COPY --from=builder dataops_ (thiếu path đích)
             CMD dataops_"]               (thiếu phần đầu, dư dấu ")
  Root cause: File bị truncate/corrupt trong một lần edit PowerShell trước đó
              dùng regex replacement bị sai pattern.
  Fix: Rewrite hoàn toàn Dockerfile thay vì patch từng dòng.
  Lesson: Khi dùng PowerShell -replace với multiline content, luôn verify toàn bộ file sau.

5. BÀI HỌC KỸ THUẬT (LESSONS LEARNED)
=============================================================================

[1] bitnami/spark đã xóa khỏi Docker Hub:
    Tag bitnami/spark:3.5 (và tất cả bitnami tags) không còn trên docker.io.
    Bitnami đã migrate sang VMware container registry từ cuối 2024.
    → Dùng apache/spark:<version> (official) thay thế.
    → apache/spark không có SPARK_MODE — phải dùng spark-class command trực tiếp.

[2] MYSQL_DNS vs MYSQL_HOST/PORT/USER/PASSWORD:
    configuration.go của dataops_backend_api đọc MYSQL_DNS (connection string),
    KHÔNG đọc từng field riêng lẻ.
    → Nếu truyền sai env var, service start OK nhưng DB connection fail silently.
    → Luôn cross-check env var names trong configuration.go trước khi đặt trong compose.

[3] Biến env dùng trong compose PHẢI khớp với config.go:
    Quy trình: đọc configuration.go → lấy đúng tên key → đặt vào compose.
    Không đoán theo convention (MYSQL_HOST etc.) mà phải xem code thực tế.

[4] Docker Healthcheck phải dùng tool có sẵn trong image:
    apache/spark image: không có python3, không có netcat (nc).
    → Dùng curl (có sẵn) để check Web UI thay vì socket check.
    → Luôn kiểm tra image có tool nào trước khi viết healthcheck.

[5] Xóa code legacy dứt khoát hơn giữ với deprecated comment:
    "Giữ backward compat" chỉ có nghĩa khi có consumer thực sự đang dùng.
    Khi không còn consumer → xóa sạch tránh:
      - Compile error khi constant bị xóa nhưng code vẫn reference
      - Confusion cho developer đọc code sau
      - Test coverage giảm do code không dùng nhưng vẫn tồn tại

[6] PowerShell multiline regex replace dễ corrupt file:
    $content -replace '(?s)(multiline-pattern)', '$1replacement'
    có thể cắt ngắn content nếu pattern không match chính xác.
    → Sau mỗi replace, verify toàn bộ file hoặc dùng apply_diff thay thế.

[7] Verify VPS purge bằng grep cross-module:
    Sau khi xóa VPS, chạy grep toàn codebase để đảm bảo không sót:
    Get-ChildItem -Recurse -Include "*.go" | Select-String "VPSMarket|VPSSnapshot"
    → Phát hiện thêm vnstock.go và influxdb.go còn reference — đã fix.
