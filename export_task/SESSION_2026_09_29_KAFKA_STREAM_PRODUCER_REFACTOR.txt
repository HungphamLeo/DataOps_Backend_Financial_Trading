2.3 Refactor Mã Nguồn dataops-stream-producer
---------------------------------------------
A. Tầng Partitioner (`pkg/producer/transactional_producer.go`):
   - Đổi tên `OKXPartitioner` -> `BinancePartitioner`.
   - Partition 0: Dedicated cho tất cả symbol tiền tố `BTC` (ví dụ `BTCUSDT`).
   - Partition 1: Dedicated cho tất cả symbol tiền tố `ETH` (ví dụ `ETHUSDT`).
   - Partition 2..N-1: Phân bổ đều các cặp altcoins / mã CK bằng thuật toán `FNV32a`.
   - `RequiresConsistency() = true` để bảo đảm ordering tuyệt đối.

B. Tầng Producer & Serialization (`pkg/producer/producer.go`):
   - Thống nhất sử dụng `IBM/sarama` SyncProducer với cấu hình:
     * `RequiredAcks = sarama.WaitForAll` (`acks=all`).
     * `Idempotent = true` + `MaxOpenRequests = 1` (Exactly-Once Semantics trên partition).
     * `Partitioner = NewBinancePartitioner`.
     * `Compression = CompressionSnappy`.
     * `Retry.Max = 5`, `Retry.Backoff = 100ms`.
   - Schema Registry & Confluent Wire Format:
     * Đóng gói payload: `[0x00][4-byte big-endian schema_id][bytes]`.
     * Graceful fallback sang JSON chuẩn nếu Schema Registry không khả dụng.

C. Tầng Dead Letter Queue (DLQ):
   - Bổ sung topic `TopicVPSMarketDLQ = "vps.market.snapshot.dlq"` trong `constants/topics.go`.
   - Tích hợp `sendToDLQ` tự động bọc metadata lỗi (`event`, `error`, `timestamp`) và route vào `binance.trade.ticks.dlq`, `binance.orderbook.snapshot.dlq`, `vps.market.snapshot.dlq`.
   - Cập nhật `pkg/producer/dlq.go` sử dụng `Balancer: &kafka.Hash{}` thay vì `LeastBytes`.

D. Tầng Ingestion Sources:
   - Binance WebSocket (`pkg/sources/binance/websocket/producer.go`):
     * Nhận và giải mã Binance Combined Stream (`@trade`, `@depth5`).
     * Chuyển đổi sang `TradeEvent` & `OrderBookEvent` chuẩn.
     * Publish thông qua `producer.Producer` có hỗ trợ Avro/JSON + DLQ.
   - VPS Market Data Poller (`pkg/sources/vps/market_data/poller.go`):
     * Parse REST response sang `VPSSnapshotEvent`.
     * Publish thông qua `producer.Producer` với `TopicVPSMarket`.

E. Server Wiring (`app/server.go`):
   - Thay thế `kafka.GetWriter` sơ sài bằng `producer.NewProducer(brokers, cfg.SchemaRegistry.URL)`.
   - Quản lý lifecycle và graceful shutdown đóng producer an toàn.
