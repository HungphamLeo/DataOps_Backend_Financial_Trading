2. KHÁM PHÁ KỸ THUẬT — TCBS iFlash API
=============================================================================

2.1 Auth Flow
-------------
  POST /gaia/v1/oauth2/openapi/token
  Body: { "apiKey": "<key>", "otp": "<Smart OTP từ TCInvest app>" }
  Response: { "access_token": "<JWT>", "token_type": "Bearer" }

  - Token là JWT Bearer, long-lived.
  - OTP là one-time (~30s TTL từ TCInvest app) — KHÔNG lưu OTP, chỉ lưu JWT.
  - Retry strategy: 4xx → NO retry (bad OTP/apiKey), 5xx → retry với backoff.

2.2 Key Endpoints Được Tích Hợp
---------------------------------
  GET /tartarus/v1/tickerCommons
      Full orderbook 3 cấp + OHLC + foreign room
      Params: ?tickers=CSV hoặc ?index=<code>  (mutually exclusive)

  GET /tartarus/v1/tickerSnaps
      Foreign room + lightweight snapshot
      Params: ?tickers=CSV

  GET /nyx/v1/intraday/{ticker}/bsa
      Buy/Sell Analysis (TCBS-exclusive: sheep/wolf/shark/all)
      Params: ?type=sheep|wolf|shark|all

  GET /nyx/v1/intraday/{ticker}/his/paging
      Tick-by-tick intraday history
      Params: ?page=&size=

  GET /tartarus/v1/derivatives
      VN30F derivative market board

  POST /gaia/v1/oauth2/openapi/token
      Auth token refresh

2.3 TCBS vs VPS — Sự khác biệt quan trọng
------------------------------------------
  Protocol   : VPS = JSON-RPC POST (session)     | TCBS = REST GET (JWT Bearer)
  Auth       : VPS = session cookie               | TCBS = JWT Bearer token
  Batch limit: VPS = ~200 symbols/batch           | TCBS = conservative 50/batch (undocumented)
  BSA        : VPS = Không có                     | TCBS = Sheep/Wolf/Shark/All (TCBS-exclusive)
  Field name : VPS = matchQty, bidQty01           | TCBS = matchQtty, bidQtty01 (double-t!)
  Change     : VPS = changePct                    | TCBS = changePercent

2.4 TCBS Index Basket Codes
----------------------------
  HOSE=1, VN30=2, HNX=3, HNX30=4, UPCOM=5
  Midcap=10, VN100=11, VNAllShare=12, VNSmallCap=13, VNXAllShare=14, VN50=15, VNSI=16

  QUAN TRỌNG: ?tickers= và ?index= là mutually exclusive —
  không truyền cả hai cùng lúc trong /tartarus/v1/tickerCommons.

8. LESSON LEARNED & GOTCHAS
=============================================================================

8.1 TCBS API Gotchas
----------------------
[1] Field naming khác VPS — QUAN TRỌNG:
    - matchQtty (double-t, KHÔNG phải matchQty)
    - bidQtty01, bidQtty02, bidQtty03 (KHÔNG phải bidQty01)
    - changePercent (KHÔNG phải changePct)
    - totalVol / totalVal (KHÔNG phải volume / value)
    → Sai field name → silent zero values trong InfluxDB — rất khó debug.

[2] Mutually exclusive params:
    ?tickers= và ?index= không dùng cùng lúc trong /tartarus/v1/tickerCommons.
    → Sai → 400 hoặc empty response từ TCBS.

[3] Batch size conservative = 50:
    Undocumented limit. get_batch_ticker_commons() và GetBatchTickerCommons()
    tự chia nhóm <= 50. Không test với 200+ symbols một lần.

[4] OTP TTL ~30s — không thể auto-refresh:
    Auth flow cần human interaction (TCInvest app) để lấy OTP mới.
    → Khuyến nghị: JWT TTL dài + monitoring alert khi 401.
    → KHÔNG thể implement fully automated token refresh.

[5] BSA = TCBS-exclusive:
    Không có endpoint tương đương ở VPS hay Binance.
    Đây là differentiator chính của TCBS — cần highlight trong docs/UI.

[6] Index basket codes là INTEGER:
    ?index=2 (VN30), KHÔNG phải ?index=VN30.
    Mapping: IndexNameToCode / TCBSIndexNameToCode.

8.2 Architecture Decisions
----------------------------
[1] VPS code không bị xoá:
    //go:build ignore trong Go, files giữ nguyên trong Python.
    Lý do: backward compat với Kafka schema registry + existing consumers.

[2] GetOrderBook reuses GetMarketSnapshot:
    Orderbook 3 cấp embedded trong market snapshot → reuse, không double-query.

[3] TCBSPoller dùng cron (không WebSocket):
    TCBS không cung cấp WebSocket public → poll interval 1 phút cho intraday.
    EOD BSA poll sau 15:05 để có đủ dữ liệu cuối ngày.

[4] Avro namespace: com.tcbs.market.events
    Tách biệt với com.binance.vps.events → không conflict trong Schema Registry.

[5] GetMarketSummary skip lỗi per-index:
    Nếu 1 index (VNINDEX/VN30/VN100) không có data → skip, không fail toàn request.
    Trả partial result + log warning.
