2.2 Fix bug logger_setup.py
    File: dataops_batch_api/log/logger_setup.py

    Vấn đề:
      - Dòng "if self._initialized:" trong __init__ có thể gây AttributeError
        nếu _initialized chưa tồn tại trên instance (edge case test reload/mock)
      - "except Exception" quá rộng — nuốt cả lỗi logic không liên quan đến import

    Fix:
      TRƯỚC: if self._initialized:
      SAU:   if getattr(self, "_initialized", False):

      TRƯỚC: except Exception:
      SAU:   except (ImportError, AttributeError):

    Thiết kế đúng:
      - "from config import Paths" trong __init__ là intentional
      - Nằm trong try/except vì logger_setup có thể import trước khi
        dataops_batch_api/ có trên sys.path
      - Fallback dùng Path(__file__).parent — luôn đúng bất kể working dir
      - Singleton LoggerManager cấu hình toàn bộ Python process qua dictConfig()
      - Các module chỉ cần logging.getLogger(__name__), KHÔNG import logger_setup

7. LESSONS LEARNED — KỸ THUẬT
=============================================================================

7.1 Sự khác biệt OKX vs Binance API

  Khía cạnh          OKX                            Binance
  ----------------    -----------------------------  ------------------------------
  Auth headers        OK-ACCESS-KEY (4 headers)      X-MBX-APIKEY + ?signature=
  Signature encoding  Base64(HMAC-SHA256)             Hex(HMAC-SHA256)
  Signature input     ts+METHOD+path+body            queryString (toàn bộ params)
  Candle endpoint     /api/v5/market/history-candles /api/v3/klines
  Candle format       [ts,o,h,l,c,vol,volCcy,...,confirm]  [openTime,o,h,l,c,vol,closeTime,quoteVol,...]
  vol_ccy index       row[6]                         row[7]
  Confirm field       row[8] (0=in-progress, 1=done) KHÔNG CÓ — mặc định 1
  Symbol format       BTC-USDT, BTC-USDT-SWAP        BTCUSDT (không gạch, không -SWAP)
  WS subscription     JSON {"op":"subscribe","args"} URL path ?streams=btcusdt@trade
  WS URL              wss://ws.okx.com:8443/ws/v5   wss://stream.binance.com:9443/ws
  Rate limit candles  20 req/2s per IP               1200 req/min per IP

7.2 Binance Futures vs OKX Swap
    OKX Perpetual: symbol "BTC-USDT-SWAP", inst_type "SWAP"
    Binance Perpetual: symbol "BTCUSDT" (giống spot), inst_type "FUTURES" hoặc "PERP"
    => Đổi inst_type="SWAP" → "FUTURES", key "swap" → "futures" trong config instruments

7.3 Binance Combined Stream format
    Single stream:   wss://stream.binance.com:9443/ws/btcusdt@trade
    Combined stream: wss://stream.binance.com:9443/stream?streams=btcusdt@trade/btcusdt@depth5
    Message wrapper: {"stream":"btcusdt@trade","data":{...}}
    => Dùng envelope.Stream để route → topic (không dùng JSON subscribe như OKX)

7.4 Go module names chưa đổi — QUAN TRỌNG
    data-stream-producer/go.mod:  module okx-stream-producer  (CHƯA ĐỔI)
    dataops_backend_api/go.mod:   module okx-analytics-api    (CHƯA ĐỔI)
    Tất cả import paths trong .go vẫn dùng "okx-stream-producer/..." và "okx-analytics-api/..."
    Đây là intentional — cần làm riêng với: go mod edit + find-replace import paths
