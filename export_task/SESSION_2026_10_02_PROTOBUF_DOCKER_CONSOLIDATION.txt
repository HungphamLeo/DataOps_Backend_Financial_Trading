2.3 Docker Infrastructure Consolidation & Security Hardening
-----------------------------------------------------------------------------
- Dọn dẹp thư mục thừa/rải rác:
  * Xóa bỏ thư mục lồng nhau `dataops_batch_api/infra_dataops_batch_trading/`.
  * Gom Dockerfile của batch pipeline về đúng chuẩn: [`dataops_batch_api/Dockerfile`](dataops_batch_api/Dockerfile).
  * Xóa bỏ các folder rỗng không cần thiết: `infra/gateway/`, `infra/load_balancer/`.

- Chuẩn hóa Dockerfiles (Multi-stage + Non-root + Healthcheck):
  * `dataops-stream-producer/Dockerfile`: Multi-stage Go build (`-ldflags="-w -s"`), base `alpine:3.19`, user non-root `appuser:appgroup`, `HEALTHCHECK` tích hợp.
  * `dataops_backend_api/Dockerfile`: Multi-stage Go build, base `alpine:3.19`, user non-root `appuser:appgroup`, `HEALTHCHECK` qua `curl http://localhost:8080/health`.
  * `dataops_batch_api/Dockerfile`: Multi-stage Python 3.11 + OpenJDK 17, user non-root `appuser:appgroup`, phân quyền thư mục `log/log_storage`.

- Nâng cấp `docker-compose.yml` tổng (Unified Production Infrastructure):
  * Mạng cô lập: Custom bridge network `dataops-internal-net`.
  * Healthchecks toàn diện: Kafka 3x (KRaft broker api check), Schema Registry (`/subjects`), MinIO (`/minio/health/live`), MySQL (`mysqladmin ping`), Redis (`redis-cli ping`), InfluxDB (`/health`).
  * Khởi động đồng bộ: `depends_on: { condition: service_healthy }` trên tất cả dependent services.
  * Resource Limits & Reservations: Giới hạn CPU và RAM cho toàn bộ 14 containers (chống Noisy Neighbor & OOM Exit Code 137).
  * Restart Policy: `restart: unless-stopped`.
  * Named Volumes bền vững: `kafka1-data`, `kafka2-data`, `kafka3-data`, `minio-data`, `mysql-data`, `redis-data`, `influxdb-data`, `grafana-data`.

3. BÀI HỌC KỸ THUẬT & QUY TẮC ĐƯỢC RÚT RA (LESSONS LEARNED)
=============================================================================

1. Polyglot Architecture & Package Isolation:
   - Golang (`dataops-stream-producer`, `dataops_backend_api`) quản lý độc lập bằng `go.mod`/`go.sum` và biên dịch ra static binary trong container Alpine nhỏ gọn (<30MB).
   - Python (`dataops_batch_api`) quản lý độc lập bằng `dataops_batch_api/requirements.txt` trong container `python:3.11-slim` kèm Java JRE cho Spark.
   - Không gộp dependencies của 2 ngôn ngữ vào cùng 1 runtime; giao tiếp thuần túy qua Kafka / S3 / REST / gRPC.

2. Production Docker Synchronization:
   - Tuyệt đối không dùng `depends_on` dạng list thuần túy cho database/broker, phải dùng `condition: service_healthy` kết hợp `healthcheck` chuẩn lệnh của service (ví dụ `kafka-broker-api-versions`, `redis-cli ping`, `mysqladmin ping`).

3. TCBS Protobuf Contract Alignment:
   - Các trường trong Protobuf phải nhất quán với InfluxDB measurements (`tcbs_market`, `tcbs_bsa`, `tcbs_intraday`, `tcbs_ohlcv`) và Open API schema specs (3-level orderbook, BSA parameters, Intraday price action).
