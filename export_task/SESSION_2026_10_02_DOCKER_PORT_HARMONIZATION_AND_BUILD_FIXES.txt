3. BÀI HỌC KỸ THUẬT & QUY TẮC BẢO TOÀN (LESSONS LEARNED)
=============================================================================

1. Quản lý phiên bản Go runtime vs Docker build container:
   - Khi chỉnh sửa go.mod, luôn kiểm tra chỉ thị `go <version>` có tương thích với base image trong Dockerfile (FROM golang:X.XX-alpine) để tránh lỗi build timeout/abort khi go mod download.

2. Nguyên tắc cô lập Port giữa các cụm dự án DataOps:
   - Khi chạy nhiều stack song song (Webcraw, Homecredit, Financial Trading), luôn thiết lập ma trận offset port cho các dịch vụ phổ biến (MinIO: 9000 -> 9010, Spark: 7077 -> 7087, Postgres/MySQL) để tránh conflict socket binding trên host Windows/Linux.

3. Quy tắc bảo toàn DB Engine:
   - Không vội vàng chuyển đổi DB Engine (MySQL <-> PostgreSQL) khi chưa có task di chuyển dữ liệu & migration schema cụ thể, nhằm duy trì tính liên tục và giảm thiểu rủi ro phát sinh bug trong các repository query hiện hành.
